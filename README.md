# zonenote

Zone color note values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/zonenote/

## Install / run

```bash
git clone https://github.com/theworker02/zonenote.git
cd zonenote
node src/cli.js
node --test
```
